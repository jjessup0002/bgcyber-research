# Performance Feedback Loop

The current audience is small and heavily invitation-driven, so it is weak proof of organic product-market fit. Track earned followers separately whenever possible: people acquired without founder invitations.

Early signals: shares, saves, meaningful comments/tags, profile visits, merchant reshares, earned follows, link/business-page activity, merchant inquiries, and merchant retention. Later signals: deal interactions/redemptions, customer acquisition, and recurring merchant value.

Initially, use external evidence to form hypotheses and local evidence to increase transferability. As BG Cyber Deals creates enough clean experiments, internal results should outweigh generic external advice. Do not hard-code a numeric weighting; document the evidence basis of each decision.
